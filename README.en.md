## Original project and changes

Based on **[MatsuriDayo/nekoray (NekoBox)](https://github.com/MatsuriDayo/nekoray)**. This fork builds on the original project with the following changes:

- Updated the application name, logo, toolbar icons, interface theme and Chinese text.
- Added an online support link, simplified the version dialog and changed window-close behavior to exit the application.
- Bundled runtime dependencies and Geo databases, and improved Windows portable and EXE installer packaging.
- Separated installed-app configuration storage and made desktop shortcut creation optional on the final installer page.

The original Git history and [GPL-3.0 license](LICENSE) are retained. Third-party components remain subject to their respective licenses.
